## 📌 About the Project

Project ini berawal dari salah satu latihan pengolahan data menggunakan **Microsoft Excel**. Setelah menyelesaikan latihan tersebut, saya mengembangkan hasil pengolahan data menjadi sebuah **interactive dashboard** sebagai portfolio project.

Tujuan dashboard ini adalah menyajikan data nilai siswa dalam bentuk visual yang lebih informatif, sehingga performa kelas maupun masing-masing siswa dapat dianalisis dengan lebih mudah.

---

## 🔄 From Excel Data to Interactive Dashboard

### 1. Data Processing — Microsoft Excel

Data nilai siswa diolah menggunakan beberapa formula Excel:

| Formula | Penggunaan |
|---|---|
| `SUM` | Menghitung total nilai |
| `AVERAGE` | Menghitung rata-rata |
| `MAX` & `MIN` | Mencari nilai tertinggi dan terendah |
| `IF` | Menentukan status berdasarkan kondisi |
| `VLOOKUP` | Menentukan predikat berdasarkan rentang nilai |
| `RANK` | Menentukan peringkat siswa |
| `COUNTIF` | Menghitung jumlah data berdasarkan kondisi |
| `AVERAGEIF` | Menghitung rata-rata berdasarkan kondisi |
| `SUMIF` | Menghitung total berdasarkan kondisi |

Hasil pengolahan tersebut kemudian digunakan sebagai dasar untuk membangun dashboard.

### 2. Dashboard Development

Dashboard dikembangkan menggunakan:

- **HTML** — struktur halaman
- **CSS** — tampilan dan layout
- **JavaScript** — interaksi, filtering, dan dynamic content
- **GitHub Pages** — deployment

## 📊 Dashboard Features

Dashboard menyediakan beberapa informasi untuk membantu melihat performa siswa dan kelas secara keseluruhan:

- 📈 **Class Performance Overview**
- 🎯 Tingkat kelulusan dan jumlah siswa yang membutuhkan remedial
- 🏅 Distribusi predikat siswa
- 📚 Rata-rata nilai setiap mata pelajaran
- 🔝 Nilai tertinggi dan terendah setiap mata pelajaran
- 🏆 Ranking siswa
- 📊 Profil kemampuan siswa
- 🗺️ Peta nilai siswa berdasarkan mata pelajaran
- 💡 Automatic insights

### 🔎 Interactive Student Search

Salah satu fitur utama dashboard adalah **student search**.

Pengguna dapat mencari atau memilih nama siswa, kemudian informasi pada dashboard akan menyesuaikan dengan siswa yang dipilih.

Informasi yang ditampilkan meliputi:

- Nilai setiap mata pelajaran
- Rata-rata nilai
- Predikat
- Ranking
- Profil kemampuan
- Perbandingan performa
- **Insight otomatis berdasarkan performa siswa**
